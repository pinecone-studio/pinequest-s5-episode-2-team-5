# OpenLab 3D — багийн ажлын хуваарь

Төсөл нэг бүхэл React апп тул **хүн бүр бүтэн төслийг татаж ажиллуулна**, харин өөрт
оноогдсон хавтас, файлуудыг "эзэмшинэ" (засвар, шинэ функцийг тэр хүн хариуцна).
Кодыг гурав хуваахад нийт ~12,400 мөр тус бүрдээ ~4,000 орчим мөр болж байна.

## Хүн 1 — 3D орчин ба гүйцэтгэл (~4,200 мөр)

Барилга, өрөө, тавилга, гэрэлтүүлэг, дүрслэлийн чанар.

| Хавтас / файл | Юу хийдэг |
| --- | --- |
| `src/world/architecture/` | Хана (нэгтгэсэн mesh), цонх, автомат шилэн хаалга, шал, тааз, таазны гэрэл |
| `src/world/furniture/` | Лабораторийн ширээ (шургуулга/хаалга), угаалтуур, шүүгээ, татах шүүгээ (fume hood), тавиур, сандал, самбар, аюулгүйн шүршүүр, гал унтраагуур, чимэглэл |
| `src/world/rooms/` (`physicsStations.tsx`-аас бусад) | 6 өрөөний байршил: Гол танхим, Коридор, Физик, Хими, Биологи, Агуулах |
| `src/world/layout.ts`, `itemsLayout.ts`, `roomVisibility.ts` | Барилгын план, өрөө/хаалга/портал, эд зүйлсийн анхны байрлал |
| `src/world/Lab.tsx`, `Lighting.tsx`, `SkyDome.tsx`, `Effects.tsx` | Угсралт, гэрэл, тэнгэр, постпроцесс (AO, Bloom, SMAA) |
| `src/world/Performance.tsx`, `StaticBatch.tsx` | DPR тохируулга, сүүдэр, шилний LOD, mesh нэгтгэл |
| `src/utils/textures.ts` | Шалны хавтан, зурагт хуудас, самбар, дэлгэцийн CanvasTexture |

## Хүн 2 — Тоног төхөөрөмж, харилцаа, туршилт (~4,200 мөр)

3D багаж хэрэгслийн загвар, барих/тавих/шалгах систем, Милликены физик.

| Хавтас / файл | Юу хийдэг |
| --- | --- |
| `src/equipment/` | Бүх багажны загвар (микроскоп, Милликены аппарат, аяга, колбо, компьютер …), `equipmentCatalog.ts`, `registry.tsx`, `ModelOr.tsx` (GLTF солих), `FittedModel.tsx` |
| `src/materials/` | Шил, хуванцар, металл, шингэний материал |
| `src/interaction/` | `Interactable` (тодруулга/prompt), төвийн raycast, барих/тавих (`Pickable`, `HeldItem`), F-ээр шалгах (`InspectMode`), гадаргуу, гаргах (`spawn`) |
| `src/experiment/` | Милликены томьёо (`millikanPhysics.ts`), дуслын симуляц (`millikanSim.ts`) |
| `src/world/rooms/physicsStations.tsx` | Милликены станц, цахилгааны станц, дүүжин, оптикийн ширээ |
| `src/world/GuideArrows.tsx` | Дараагийн алхам руу заах шалны сумнууд |
| `src/store/useExperimentStore.ts`, `useInventoryStore.ts` | Туршилтын төлөв, хэмжилт; дэлхий дээрх/гарт байгаа эд зүйлс |

## Хүн 3 — Удирдлага, UI ба апп-ын төлөв (~4,100 мөр)

Тоглогчийн хөдөлгөөн, бүх HUD/цонх, тохиргоо, дуу.

| Хавтас / файл | Юу хийдэг |
| --- | --- |
| `src/controls/` | Тоглогчийн контроллер (rapier), физикийн алхам, товчлуурын зураглал, pointer lock, глобал товч/хулганы удирдлага |
| `src/ui/` | HUD, цэс, тохиргоо, тэмдэглэл, End/тайлан, Tools шургуулга, робот туслах, жижиг газрын зураг, **микроскопын харагдац**, **компьютерын өгөгдлийн апп**, ачааллын дэлгэц, гар утасны удирдлага |
| `src/store/useGameStore.ts`, `useSettingsStore.ts`, `useLoadingStore.ts` | Горим, панел, робот, тохиргоо (localStorage), ачааллын явц |
| `src/utils/sounds.ts`, `fonts.ts`, `constants.ts`, `device.ts`, `lazy.ts`, `DebugBridge.tsx` | Дуу, фонт, тогтмолууд, тест хийх debug гүүр |
| `src/App.tsx`, `src/main.tsx`, `src/index.css`, `tailwind.config.js` | Апп-ын угсралт, загвар |

## Хэсэг хоорондын "гэрээ" (өөрчлөхөөсөө өмнө ярилцах)

- **1 ↔ 2:** Өрөөнүүд багажийг `<Microscope />`, `<MillikanStation />` гэх мэт компонентоор
  байрлуулна. Ширээнүүд `registerSurface()`-ээр гадаргуугаа бүртгүүлж, шургуулга/хаалганууд
  `<Interactable>` ашиглана. Багажны байрлалыг `itemsLayout.ts`-д тохирно.
- **2 ↔ 3:** UI нь `useExperimentStore`, `useInventoryStore`-ийг уншина. Товчлуурын
  удирдлага (`useGameKeys.ts`) нь `interactables` бүртгэл болон `heldApi`-г дууддаг.
  Компьютер руу ойртох камер `cameraDock`-оор (Player) ажиллана.
- **1 ↔ 3:** Өрөөнүүд `useGameStore`-ийн `activeRooms`, `playerState`-ийг ашиглана.
  Чанарын тохиргоо (`QUALITY_PRESETS`) нь Effects/Lighting/Performance-д нөлөөлнө.
- Store-ийн бүтэц, `layout.ts`-ийн координат, `equipmentCatalog.ts`-ийн `EquipmentKind`
  гэх мэт **дундын төрлийг** өөрчлөх бол бусаддаа урьдчилан хэлнэ.

## Хамтран ажиллах дүрэм (Git)

1. Нэг хүн GitHub дээр repo үүсгэж, бусад хоёрыг collaborator болгон нэмнэ.
2. `main` салбарт шууд push хийхгүй. Хүн бүр өөрийн салбар дээр ажиллана:
   `world/...`, `equipment/...`, `ui/...` (жишээ: `ui/mongolian-language`).
3. Pull Request нээж, өөр нэг гишүүнээр шалгуулаад merge хийнэ.
4. Merge хийхээс өмнө `npm run build` алдаагүй гарах ёстой.
5. Өдөр бүр `main`-ийг өөрийн салбарт татаж (`git pull origin main`) зөрчил багасгана.

## Ажиллуулах

OpenLab нь ChemQuest repo-ийн `openlab-3d/` хавтсанд байрладаг тусдаа вэб апп.

```bash
cd openlab-3d
npm install
npm run dev                 # OpenLab-ийг дангаар нь: http://localhost:5173
npm run build:chemquest     # ChemQuest-д зориулж ../public/openlab руу build хийнэ
```

Дараа нь repo-ийн үндсэн хавтсанд `npm run web` ажиллуулаад хаб дээрх **OpenLab**
байшингийн хаалгаар орно. Гурван хэсэг (Хүн 1, 2, 3) бүгд `openlab-3d/` дотор орсон
байх ёстой, эс бөгөөс build амжилтгүй болно.

## Цааш хийж болох ажлын санаа

- **Хүн 1:** өрөө бүрт илүү нарийн чимэглэл, бодит GLTF загвар оруулах, гэрэлтүүлэг/материалыг сайжруулах, Low тохиргоонд гүйцэтгэлийг дахин шалгах.
- **Хүн 2:** шинэ туршилт нэмэх (дүүжингийн хугацаа хэмжих, титрлэлт), багажны дуу/анимаци, илүү олон дээж.
- **Хүн 3:** интерфейсийг монгол хэл рүү орчуулах, сургалтын (tutorial) горим, хүртээмжийн шалгалт, гар утасны UI-г сайжруулах.
